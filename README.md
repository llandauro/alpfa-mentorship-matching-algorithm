# Mentorship Matchmaker: Weighted Gale-Shapley Implementation

This project is a full-stack mentorship matching tool that combines a **Google Sheets frontend** with a **Python/Flask backend**. It uses a weighted scoring engine and the Gale-Shapley algorithm to create stable, optimized pairings between mentors and mentees.

## The Problem & Solution

### The Problem
Matching mentors and mentees manually is time-consuming and often fails to balance competing priorities (e.g., matching by technical field vs. ensuring the mentor has more seniority).

### The Solution
I implemented a Weighted Gale-Shapley Algorithm, a concept from my Algorithm Design class:
1.  **Dynamic Scoring:** The backend calculates compatibility based on five metrics: Experience, Field, Career Stage, Studies and Objectives/Capacities.
2.  **User-Defined Weights:** Through the Google Sheets "Settings" tab, users can prioritize specific criteria (e.g., setting "Experience" weight to 10 and others to 0).
3.  **Stable Marriage Logic:** The algorithm ensures a "stable" outcome where no two individuals would both prefer to be with each other over their assigned partners, reaching a mathematical equilibrium.

## Project Structure
* **/backend**: Python Flask server, `matchmaker.py` (Logic), and `requirements.txt`.
* **/frontend**: Google Apps Script files (`matchingLogic.js`) for Google Sheets integration.

## Logic & Assumptions
* **One-to-One Matching:** Each participant is assigned exactly one partner.
* **Dataset Parity:** The algorithm functions optimally with an equal number of mentors and mentees. If counts are unequal, the system pairs as many as possible; remaining participants remain unmatched.
* **Data Cleaning:** The backend automatically handles case-sensitivity and whitespace in fields like "Field" or "Studies" to ensure matching accuracy.

## Setup & Installation

### Backend Setup
1. The Python backend manages the Gale-Shapley scoring engine. Navigate to the `backend` directory to initialize the environment:
    ```bash
    cd backend
2. Dependencies: 
    #### Option A: Using Conda
    A1. Create the enviornment:
    ```bash
    conda env create -f environment.yml
    ```
    A2. Activate it:
    ```bash
    conda activate matching-ts-env
    ```
    #### Option B: Using Pip
    B1. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3. Run the server: 
    ```bash
    python main.py
     ```
! **Important**: Keep this terminal window open while testing. The backend server must be active for the Google Sheet to communicate with the matching algorithm.

### Connect the Cloud (Ngrok)
Since Google Sheets cannot "see" your localhost, you must create a public tunnel to port 8000:
1. Install ngrok
2. In a new terminal, run: ```ngrok http 8000``` (Note: It must be port 8000 to match the backend configuration in main.py.)
3. Copy the Forwarding URL (e.g., https://random-id.ngrok-free.dev).
! **Important**: Keep this terminal window open while testing; closing it will disconnect the tunnel.

### Frontend Setup
I have provided a Google Sheet with anonymous dummy data for testing. There is no sensitive information or real-user data included in this dataset.
1. Open the Template: [Mentorship Program Dummy Data](https://docs.google.com/spreadsheets/d/1a9JEu53M2yce5HpTWkgqW-DQCmtkMLRJ_ADNq7y49g0/edit?usp=sharing)
2. Link the Backend: In the Settings tab of the sheet, paste your ngrok Forwarding URL into the "Server URL" field.
3. Authorize Access: When you first run the script, Google will prompt you to authorize the Apps Script. Follow the prompts to allow the script to connect to your external server.

### Testing the Algorithm
1. Configure Weights: In the "Settings" tab of the Mentorship Program Dummy Data Sheet, adjust the importance of different metrics.
2. Execute: Click the "Run Matching" button in the Google Sheet menu.
3. Verify: Inspect the Results tab to see the stable pairings generated by the backend.
